# Разработка

Требуются Node.js 24+, npm и BB 0.43+ для сборки плагина. SDK закреплён на 0.4.84; это исходный проверенный контракт.

```sh
npm ci
npm run check
npm test
npm run build
cd companion/aivech
npm ci
npm test
```

CI проверяет TypeScript и тесты плагина/companion. Сборку BB и проверку реального интерфейса выполняем локально перед релизом: CI не содержит установленного BB и Telegram-секретов.

Перед изменением API читать актуальные SDK-декларации. Обычные обновления не должны сбрасывать plugin storage: там привязки тем и очередь. Миграции данных должны сохранять существующие привязки. Изменения транспорта проверять на повторных updates, рестарте, устаревших кнопках, 429 и одновременном ответе в BB.

Текущая установка отслеживает локальную папку. Обновление: получить проверенный commit, выполнить проверки/сборку и `bb plugin reload telegram-projects`. Companion развёртывается отдельно; не запускать второй poller. Теги `vX.Y.Z` неизменяемые: исправление выпускается новым тегом.

Не коммитить токены, private/, конфигурацию владельца с секретами, базы, аудио, сообщения или пользовательские артефакты. Перед публичным релизом пройти docs/roadmap.md. Публичная лицензия пока не выбрана; package.json помечен UNLICENSED.
