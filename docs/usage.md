# Как общаться с BB в Telegram

## Новый разговор

1. Открой основную тему проекта и отправь `/menu`.
2. Выбери «Новый чат». Пока пустая сессия не создаётся и модель не запускается.
3. При необходимости выбери `/section` — папку, затем `/model` — агента и модель.
4. Напиши задачу или отправь голос. BB создаст видимый чат; ответ придёт в эту тему.

Настройки по умолчанию берутся из BB. Для корня используется текущее default environment проекта; для раздела — точный host/path Projects & Sections. Для проекта BB-сервис это отдельная папка Documents/BB-сервис, что проверено сквозным тестом. Открытый чат продолжает работать с тем окружением, в котором был создан.

## Дополнительные темы

Создай новую тему в Telegram и отправь `/project`. Выбери проект: теперь эта тема — дополнительный разговор того же проекта. В одной теме активен один чат BB. Для двух параллельных разговоров используй две темы.

Основные автоматически созданные темы проекта, «Навигация» и «SMS» сохраняют своё назначение. Выбор другого проекта оттуда отправляет меню в его основную тему. Дополнительную тему можно перепривязать к другому проекту; текущая сессия сохранится в BB. Повторный выбор того же проекта сохраняет подключение.

## Уже существующий чат

`/chats` → нужный чат → посмотри состояние и каталог → «Подключиться». Можно сначала запросить последний ответ. Команда `/use thr_...` открывает такую же карточку по ID.

При подключении старая переписка не выгружается автоматически. Приходят новые завершённые ответы и вопросы. `/history` показывает последний ответ; кнопка «Открыть чат в BB» ведёт к полной истории. Скрытые и архивные сессии не подключаются из этого меню.

`/disconnect` прекращает пересылку и отправку в этот чат. `/new` готовит новый разговор; прежняя история остаётся. Эти команды не останавливают старого агента — для остановки есть `/stop` с подтверждением.

## Модели

`/model` в новом чате показывает агентов, затем модели из BB. В существующем чате предлагает изменить модель текущего провайдера, когда запуск свободен. «Другой агент → новый чат» создаёт новую сессию с первого сообщения; внутренний контекст между провайдерами не копируется.

Модель других чатов не меняется. Дополнительные параметры reasoning/permissions/service tier пока редактируются в BB и наследуются по его правилам. «По умолчанию BB» возвращает выбор провайдера нового чата к настройкам BB.

## Сообщения, голос и вопросы

Обычный текст продолжает текущий чат. Если агент занят, BB применяет свою штатную очередь/steering. `/say /команда` передаёт текст, начинающийся со слеша, самому агенту. Остальные неизвестные команды не отправляются агенту автоматически.

Голос до 10 минут/15 МБ автоматически распознаётся текущей службой BB. Транскрипт появляется перед отправкой в чат; следующей репликой его можно исправить. Это автоматическая отправка без отдельного подтверждения транскрипта.

Если пришёл штатный вопрос BB: выбери кнопку либо нажми Telegram «Ответить» на его карточку и напиши текст. Свободный ответ доступен, когда его разрешает вопрос. Разрешения отвечаются отдельными кнопками «Разрешить один раз»/«Отказать». Если вопрос уже закрыт в BB, старая кнопка ничего не разрешает. Несколько вопросов, множественный выбор и специфические формы открываются в BB.

Некоторые провайдеры не создают интерактивных вопросов в обычном режиме: их текстовые вопросы приходят как обычный ответ агента. Rich Messages можно выключить настройкой richReplies, если клиент отображает их неудобно.

## Задачи

`/tasks` показывает активные Tasks выбранного проекта, включая дополнительную тему после очередной синхронизации. Сообщение агенту само по себе не создаёт карточку Tasks. Создание и сложное управление задачами пока выполняются внутри BB.
